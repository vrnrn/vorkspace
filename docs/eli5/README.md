# Documentation, in plain English

The [build guide](building.md) explains how to run the app. The [architecture guide](architecture.md) explains which part does what, and the [repository map](repository.md) helps you find its code.

Other guides explain [saved data](data-storage.md), [providers](providers.md), [remote machines](remote-access.md), [voice](vox.md), [Bot Channels](channels.md), [visuals](visuals.md), [testing](testing.md), and [updates](updates.md).

Cargo builds the Rust desktop. Node.js is used for developer tools and remote hosts. Someone running the packaged desktop does not need Cargo.
