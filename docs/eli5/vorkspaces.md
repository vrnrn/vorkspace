# Vorkspaces, in plain English

A vorkspace is a bundle of the folders and Bots you use for one kind of work, like "Main" or "Side projects". The name at the top left of the window shows which one you are in. Click it to switch, make a new one, or manage them.

The same folder can be in more than one vorkspace, and its sessions show up in each. Taking a folder out of a vorkspace only hides it there; nothing is deleted. Bots belong to one vorkspace each: a Bot you create joins the vorkspace you are in, and adding it to another vorkspace moves it there. The first time you open this version, all your existing folders and Bots go into one vorkspace called Main.

The left side now lists sessions instead of projects. Anything running or waiting for approval is listed first (up to five); otherwise you see your three latest. Each card shows which AI ran it, which project it is in, and the Bot that started it, if any. To pick a different project, use the project name at the top of the sidebar. A Bot's floating panel now just shows its documents.

**Manage vorkspaces…** lets you rename a vorkspace, add or remove its folders and Bots, switch to it, or delete it. You always keep at least one.

Each vorkspace is meant to get its own window. That is being built in steps. Already, the app keeps one shared list of vorkspaces for all windows, lets only one window run reminders and automations, and never lets two windows run the same session. Bots, voice and a few other background parts still need the same treatment before a second window can open.

The [technical guide](../vorkspaces.md) has the details.
